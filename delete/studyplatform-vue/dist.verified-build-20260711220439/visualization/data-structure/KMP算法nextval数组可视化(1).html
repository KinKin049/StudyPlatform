nextval 规则

  1. 先按普通 KMP 构造 `next` 数组。
  2. `nextval[0] = -1`。
  3. 若 `next[j] == -1`，则 `nextval[j] = -1`。
  4. 若 `P[j] != P[next[j]]`，则 `nextval[j] = next[j]`。
  5. 若 `P[j] == P[next[j]]`，回退后仍会比较同一字符并失配，令 `nextval[j] = nextval[next[j]]`。
  6. 匹配阶段失配时，主串 `i` 不回退，直接令 `j = nextval[j]`。
