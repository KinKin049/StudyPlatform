## 一、运算符与表达式（4道错题）

### 1. 自增自减
```
a++ + ++a：从右到左扫描，++a立刻生效返回新值，a++返回旧值再变
a=5: 先++a得6，再a++返回6，结果12
```

### 2. 短路求值 + 自增
```
x++ && y++：x++返回值判断短路，再处理自增副作用
x=1: x++返回1(真)，不短路，y++返回0(假)，z=0
```

### 3. 类型转换
```
(float)(a+b)/2 → 浮点除法，结果是浮点
(int)截断小数，不是四舍五入
float + int = float
```

### 4. 进制输出
```
%o 八进制不带前缀
%#o 八进制带前缀0
%x 十六进制不带前缀
%#x 十六进制带前缀0x
```

## 二、控制结构（2道错题）

### 5. continue
```
continue = 跳过本轮，回到循环头（i++）
break = 跳出整个循环
口诀：continue本轮作废，break整个结束
```

### 6. 冒泡排序第一轮
```
{5,3,8,1} 第一轮：相邻比较交换
5>3交换→{3,5,8,1}, 5<8不动, 8>1交换→{3,5,1,8}
第一轮只确定末尾最大值，不是一次排完
```

## 三、数组与排序（2道错题）

### 7. 选择排序填空
```
k=i（假设当前位置最小）
遍历中 a[j]<a[k] 则 k=j（更新最小下标）
k!=i 才交换
口诀：k记最小下标，初始k=i，遍历更新k=j，k不等于i就交换
```

### 8. 冒泡排序填空
```
内层：j < n-1-i（不是j < i-1）
选择内层：j从i+1开始
冒泡内层：j < n-1-i
```

## 四、字符串（4道错题）

### 9. strlen vs sizeof
```
strlen("abc\0def") = 3（到\0就停）
sizeof("abc\0def") = 8（算全部含末尾\0）
```

### 10. 字符串比较
```
strcmp(s1,s2)==0 → 比内容
s1==s2 → 比地址（错）
strlen相等 → 只比长度不比内容（错）
```

### 11. 含空格输入
```
scanf("%s",s) → 遇空格停
gets(s) → 读整行含空格
```

### 12. && 和 || 搞混
```
不是A且不是B → !A || !B（用或）
不是 !A && !B（用且，永远为假）
```

## 五、函数与编程题（4道错题）

### 13. = 和 == 混淆
```
if(a=5)  → 赋值，永远为真
if(a==5) → 比较，判断相等
写if时必须检查是=还是==
```

### 14. 数组元素要直接操作
```
错误：复制到局部变量再修改（改不了原数组）
正确：直接 arr[i] 操作
```

### 15. 素数判断
```
能整除 → 不是素数 → return 0
全不能整除 → 是素数 → return 1
```

### 16. 变量名重复
```
函数参数char *s，函数内又int s → 重名冲突
计数变量换个名字，如cnt
```

## 六、指针（7道错题）

### 17. *p1=*p2 vs p1=p2
```
*p1=*p2 → 改值 → a变成b的值
p1=p2   → 改指向 → a不变
```

### 18. 函数内改指针本身
```
fun(int *p) { p=NULL; } → 只改副本，main的p不变
fun(int *p) { *p=100; } → 改值，main的a变了
```

### 19. 二级指针解引用
```
*p = 值     → 改变量
p = 地址    → 改自己（副本）
*pp = 地址  → 改一级指针指向
**pp = 值   → 改变量
```

### 20. *pp=&b后改指向
```
*pp=&b → p指向b → 之后*p操作的是b不是a
```

### 21. 传&p进函数
```
fun(&p) → pp指向真的p → *pp=NULL改的是main的p
```

### 22. 指针交换值vs交换指针
```
交换*a和*b → 改了原变量
交换a和b（指针本身）→ 只改副本，原变量不变
```

### 23. 指针运算
```
*(p+2) = a[2] = p[2]（三种写法等价）
p2-p1 = 元素个数，不是字节数
```

### 24. 结构体定义
```
struct b; → 只有类型名，没定义变量，编译错误
struct {int x;} b; → 正确
```

### 25. 共用体字节序
```
union赋值后读不同类型，小端序读最低字节
0x41424344 → u.c = 0x44 = 'D'
c[0]='A'(65), c[1]=0 → u.i = 65（小端序）
```

## 九、公共基础（4道错题）

### 27. 满二叉树公式
```
叶子节点 = 2^(深度-1)  ← 不是总节点数！
总节点 = 2^深度 - 1
```

### 28. 调试vs测试
```
测试(testing) → 发现错误
调试(debugging) → 改正错误
```

### 29. 选择vs投影
```
选择 σ → 选行（元组）→ 满足条件的记录
投影 π → 选列（属性）→ 指定的字段
口诀：选行=选择，选列=投影
```

### 30. SQL聚合函数
```
聚合函数只有5个：COUNT、SUM、AVG、MAX、MIN
WHERE不是聚合函数，是条件关键字
```

### 31. 二分查找前提
```
必须数据有序
不适合链表（需要随机访问）
```

## 十一、小黑课堂真题二 新增（6道新错题）

### 35. 进制转换
```
%d 十进制，%o 八进制，%x 十六进制
33 → %o = 41（33=4×8+1）
33 → %x = 21（33=2×16+1）
```

### 36. 强制类型转换优先级
```
(int)1.99*3 → ((int)1.99)*3 = 1*3 = 3
不是 (int)(1.99*3) = (int)5.97 = 5
强制转换只对紧挨着的值有效！
```

### 37. 流程图基本图形
```
椭圆 = 起止框
矩形 = 处理框
平行四边形 = 输入输出框
菱形 = 判断框
```

### 38. 软件设计工具
```
设计工具：程序流程图、N-S、PAD、HIPO、判定表、PDL
DFD（数据流图）属于需求分析工具，不是设计工具
```

### 39. 系统结构图宽度
```
宽度 = 同一层次上模块总数的最大值
不是最底层的模块数，是取各层最大值
```

### 40. 自增运算符与赋值
```
sum=pad=5; pAd=sum++;
→ pAd=5, sum=6, pad不变仍然是5
pAd++和++pAd改变的是pAd指向的值，不影响pad
后置++先用后加，不影响其他变量
```

## 十二、小黑课堂真题三 新增（7道新错题）

### 41. 栈的元素个数
```
栈空间S(1:60)，top=61初始，top=1时
元素个数 = 61 - 1 = 60个
top从哪来减到哪就是元素个数
```

### 42. 八进制转义字符
```
'\141' → 八进制转义字符（1-3位数字）
'\x41' → 十六进制转义字符（x开头）
141(八进制) = 97(十进制) = 'a'
```

### 43. 函数返回类型
```
函数定义int fun() → 返回类型是int
不管return后面是什么，都按函数定义的类型返回
口诀：返回类型看函数定义，不看return的值
```

### 44. 形参vs实参
```
形参 = 函数定义中的参数（变量，要分配内存）
实参 = 函数调用时传的值（可以是常量、变量、表达式）
形参不能是常量或表达式，实参可以
```

### 45. 函数指针赋值
```
int (*f)(int,int) = fun;  // 正确：函数名直接赋值
f = fun;    // 正确
f = fun();  // 错误：fun()是调用，返回值不是函数地址
```

### 46. rand()取值范围
```
rand()%10000 → 0~9999
rand()%10000/100.0 → 0~99.99（浮点除法）
注意：用100.0而不是100，否则是整数除法
```

### 47. 关系代数除运算
```
SC/S → 除运算：S中所有学生都选修的课程
选择σ → 选行，投影π → 选列，除÷ → 找共同
```
