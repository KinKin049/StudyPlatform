KMP 规则

  1. `next[j]` 表示模式串第 `j` 位失配时，`j` 应回退到的位置。
  2. 构造 next 时使用两个指针 `j` 和 `k`，`k` 表示当前可复用的最长相等前后缀长度。
  3. 匹配时若 `S[i] == P[j]`，则 `i++`、`j++`。
  4. 匹配时若失配，主串指针 `i` 不回退，只令 `j = next[j]`。
  5. 若 `j == -1`，说明模式串无法继续回退，下一步令 `i++`、`j++`。
